Aplicar los conocimientos adquiridos mediante el desarrollo de una calculadora que permita realizar operaciones matemáticas utilizando métodos independientes, parámetros y valores de retorno.

Se deberá desarrollar una aplicación de consola en C# que presente un menú interactivo para realizar las operaciones de suma, resta, multiplicación y división.

Cada operación tendrá que implementarse mediante un método independiente, aplicando los principios básicos de modularización y reutilización de código.

El sistema validará las entradas del usuario, impedirá divisiones entre cero y permitirá realizar múltiples operaciones hasta que se seleccione la opción de salir.

El desarrollo seguirá una secuencia ordenada, garantizando la trazabilidad de la solución.
